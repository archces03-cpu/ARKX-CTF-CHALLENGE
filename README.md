# ARKX CTF - AI Security Assessment Portfolio

**Author:** Ces Ezekiel  
**Focus:** Agentic AI Security | LLM Tool Abuse | Vulnerability Assessment

## Overview

This repository documents my practical security assessment of the ARKX CTF challenge environment. The work explores vulnerabilities in AI-powered agents, tool integrations, configuration processors, and backend services.

The portfolio includes technical walkthroughs, observed security weaknesses, impact analysis, remediation recommendations, and challenge completion evidence.

## Challenge Reports

### Advanced Track

- **Level 5 - Bad Robot:** Insecure expression evaluation and command execution.
- **Level 7 - Master of Resources:** MCP resource exposure and authorization weaknesses.
- **Level 9 - Blind Network Ninja:** Blind command injection and information disclosure.

### Expert Track

- **Level 6 - The Shape Shifter:** Unsafe YAML deserialization.
- **Level 7 - The Octopus:** Credential handling, cache processing, and authorization weaknesses.
- **Level 8 - The Heist:** Time-of-check to time-of-use (TOCTOU) race condition.

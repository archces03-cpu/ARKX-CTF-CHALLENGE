# ARKX CTF - Security Research Portfolio

A documented collection of security challenges completed on the ARKX CTF platform. This repository presents practical security testing, vulnerability analysis, exploitation findings, evidence, and recommended mitigations.

## Project Overview

The portfolio covers six challenges across the Advanced and Expert tracks. Each write-up documents the vulnerability investigated, the testing methodology, observed results, security implications, and recommended remediation.

## Challenge Write-ups

### Advanced Track

| Level | Challenge | Focus |
|---|---|---|
| 5 | Bad Robot | Unsafe expression evaluation |
| 7 | Master of Resources | MCP resource access and authorization |
| 9 | Blind Network Ninja | OS command injection and information disclosure |

### Expert Track

|---|---|---|

## Repository Structure

- `Advanced-Track/` - Advanced challenge reports.
- `Expert-Track/` - Expert challenge reports.
- `Full-Assessment/` - Consolidated assessment reports and supporting documentation.

## Methodology

Each challenge report is organized around:

1. Challenge overview and objective.
2. Testing methodology and exploitation process.
3. Observed results and evidence.
4. Root cause analysis.
5. Security impact and severity.
6. Relevant CWE and OWASP mappings.
7. Recommended remediation.
8. Lessons learned.

## Security Learning Outcomes

The exercises demonstrate practical understanding of:

- Input validation and injection vulnerabilities.
- Authorization enforcement in MCP environments.
- Secure handling of serialized data.
- Authentication and session trust boundaries.
- Race conditions and transactional integrity.
- Information disclosure and secure error handling.

## Disclaimer

This repository documents security research conducted in the authorized ARKX CTF challenge environment. The techniques are presented for educational purposes and defensive security awareness. They should only be used in environments where testing is explicitly authorized.
